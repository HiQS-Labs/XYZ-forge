You are a headless builder in the **xyz-3-agents-swarm** repo (CWD = repo root). Build ONE
dependency-free renderer + its generated artifact + a deterministic refresh test. Additive only. Do
not change `ROADMAP.md`'s content or any file outside the allowlist.

## What to build

1. **`utils/roadmap-dashboard.sh`** (NEW) — a dependency-free renderer (bash + Node stdlib only, same
   "no external deps" rule as `utils/swarm-preflight.sh`; stock macOS **bash 3.2** + BSD tools). It:
   - Reads the canonical root `ROADMAP.md`.
   - Parses the `## Ledger` subsections (`### Queue / parked intake`, `### In progress`,
     `### Completed`, `### Deferred · vision`) — each is a list of `- **<title>** <emoji> …` bullets
     with a trailing `→ [doc](path)` and often a `· [#N](issue-url)` link.
   - Writes **`ROADMAP-DASHBOARD.md`** (NEW, repo root): a generated, read-only dashboard with
     (a) a top banner `<!-- GENERATED by utils/roadmap-dashboard.sh — DO NOT EDIT; edit ROADMAP.md -->`,
     (b) a summary count line per section + a status-emoji tally (🟢 🟡 ⏸️ ⛔ ✅ 🔮 🔲),
     (c) one compact table per section: `Item | Status | Links`.
   - Supports `--check`: regenerate to stdout/temp and exit non-zero if it differs from the committed
     `ROADMAP-DASHBOARD.md` (drift detection), exit 0 if in sync. Default (no flag): (re)write the file.
2. **`ROADMAP-DASHBOARD.md`** (NEW, repo root) — the generated artifact, committed in sync with the
   renderer's output (run `bash utils/roadmap-dashboard.sh` and commit the result).
3. **`test/roadmap-dashboard.sh`** (NEW) — a standalone test (mirror `test/swarm-preflight.sh` style:
   `pass`/`fail` counters, exit 1 on any fail) that asserts: the renderer runs clean; `--check` passes
   on the committed artifact (no drift); the artifact carries the DO-NOT-EDIT banner; the section
   counts match what's actually in `ROADMAP.md`. Then register it in `validate.sh` (add the one line
   that runs `test/roadmap-dashboard.sh`, matching how the other `test/*.sh` are wired).

## Objective gate (what the marathon's --pre-advance-cmd runs)
```
bash test/roadmap-dashboard.sh
```
It must pass: renderer works, `--check` shows no drift, banner present, counts correct.

## How to verify before you hand off
```
bash utils/roadmap-dashboard.sh            # regenerate the artifact
bash utils/roadmap-dashboard.sh --check    # must exit 0 (in sync)
bash test/roadmap-dashboard.sh             # the gate — all assertions pass
```

## Hard rules
- **Additive + derived only.** Do NOT edit `ROADMAP.md`'s content, move execution detail into it, or
  alter the pointer/ledger contract. The dashboard is a read-only derived view (GH-27 non-goals).
- **No external dependencies / no web app / no server / no `tick`/relay/schema work** (GH-27 non-goals).
- **bash 3.2 + BSD-portable** (no bash-4 `${,,}`, use `tr`; POSIX character classes), like the other
  `utils/*.sh`.
- **Do not `git commit`** — the harness commits. Do not push. Touch ONLY the four allowlisted paths.
- Keep the parser resilient to the ledger evolving (match on the `###` section headers + `- **…**`
  bullet shape + the status emoji), so it doesn't overfit one snapshot (GH-27 failure mode).
