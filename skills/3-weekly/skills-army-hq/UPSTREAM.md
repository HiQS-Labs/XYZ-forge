# Upstream: HiQS-Labs/XYZ-skills-army-mini

This folder is a **vendored copy**. Since 2026-10-01 the canonical upstream for Skills Army HQ is
[HiQS-Labs/XYZ-skills-army-mini](https://github.com/HiQS-Labs/XYZ-skills-army-mini). Make changes there,
not here.

- **Freshness:** XYZ Forge refreshes this copy with an occasional vendor PR from a tagged mini release.
  There is no freshness guarantee. For the newest version, use the upstream repository.
- **Drift warnings:** a stale copy here can make the drift check report Skills Army HQ itself as drifted.
  That is expected and is a warning only; drift does not block deploys unless a device opts in.
- **Retired:** `push-to-skills-army-mini` (forge → mini republish) must not be run. It would overwrite
  upstream.
