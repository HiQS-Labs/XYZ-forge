# GH-348 · a parity gate that can actually fail

## Status
| What was just completed | What's next |
|---|---|
| `run_qp_sh()` added (`XYZ_PYTHON=0`); Scenario T's left side repointed; loud `SKIP` when `node` is absent instead of a silent fallback; new in-run mutation self-check. **61/0**, and the mutation that previously left the file at 60/0 now yields **59/2**. | Review + merge. |

## The bug

- `test/marathon-plan.sh` `run_qp()` invoked `bash "$QP"` and **never set `XYZ_PYTHON`**.
- `utils/marathon-plan.sh:6` reads `${XYZ_PYTHON-1}` — **default 1**, i.e. reroute to Python.

So `run_qp` was the Python lane, and Scenario T — labelled *"matches between shell and
`XYZ_PYTHON=1`"* — compared the Python lane against the Python lane.

Demonstrated by mutation:

```bash
sed -i '' '956s/GENERATED by/MUTATED-BASH by/' utils/marathon-plan.sh
bash test/marathon-plan.sh
#   PASS: T: explicit zones dry-run output matches between shell and XYZ_PYTHON=1
#   PASS: T: rendered MARATHON-PLAN doc matches between shell and XYZ_PYTHON=1
#   marathon-plan: 60 passed, 0 failed
```

A one-line corruption of the engine the test claimed to compare against changed nothing.

## Why this one mattered more than a generic coverage gap

`marathon-plan` is the **deliberate exception** to GH-308's Python-authoritative policy —
`utils/marathon-plan.sh` stays dual-maintained — so Bash↔Python drift here is a live, expected risk.
It has already happened twice: **GH-154** (the copy was missing the GH-48 zone model) and **GH-255**
(two further gaps, papered over by pre/post-processing *around* the copied program). Scenario T was
added by GH-154 specifically to prevent the third instance, and could not.

## The fix

1. **`run_qp_sh()`** — `XYZ_PYTHON=0`, the Bash/node engine, explicitly. Scenario T's left side now
   uses it. The other 58 cases keep `run_qp` on purpose: unset is what production runs, so they are
   correctly exercising the live lane.
2. **Loud `SKIP` when `node` is missing.** The Bash engine hard-requires it
   (`utils/marathon-plan.sh:146`). Falling back to `run_qp` there would restore the exact tautology —
   and would look like a pass. A new `skip()` helper counts and reports skips in the summary line.
3. **An in-run mutation self-check.** The test renders with a mutated copy of the Bash engine and
   asserts the difference **is** detected. Without it, a future refactor could quietly point both
   sides at one lane again and every assertion here would keep passing. Its failure message names
   both possible causes rather than guessing one.

## Acceptance, as the issue specified

> re-run the mutation and Scenario T must FAIL. A fix that leaves the suite at 60/0 under that
> mutation has not fixed anything.

Observed after the fix:

```
  PASS: T: explicit zones dry-run output matches between the BASH engine and XYZ_PYTHON=1
  FAIL: T: rendered MARATHON-PLAN doc drifted between the BASH engine and XYZ_PYTHON=1
  FAIL: T: mutation self-check is inert — ...
  marathon-plan: 59 passed, 2 failed
```

The dry-run assertion still passes under this particular mutation, correctly: the `GENERATED by`
banner appears only in the **rendered doc**, not in the dry-run report. That is why the self-check
compares the rendered doc.

Clean tree: **61 passed / 0 failed**. No-node PATH: 57 passed, 1 failed, **2 skipped** — the single
failure (`F: json lines not all valid`) reproduces identically on the pre-fix file, so it is
pre-existing and out of scope.

## The pattern, now three-for-three this week

An assertion that compares a thing to a freshly-derived copy of itself:

- **this issue** — the parity test compared the Python lane to the Python lane
- **#342** — GH-281's Sentinel test `sed`-extracted the helpers from the *Bash* file, so it passed for
  a year while the shipped lane had zero references to the feature
- **#351** — the dashboard test regenerates the artifact it then validates

In all three the output reads as coverage and the gap is invisible from the pass line. Worth a
standing habit: **for any assertion of the form "A matches B", prove A and B can differ.**
