## Problem
The diagram HTML generated by `utils/swe-diagram` has no font picker — the rendered diagram surface (nodes, edge labels, group labels, title) is locked to the default system/sans font with no way to switch to a display font for presentation use.

## Fix direction
Add a font selector to the generated HTML's toolbar (default sans + "Indie Flower"), self-contained — no external font CDN — either embedding the font (e.g. base64 `@font-face`) or falling back to whatever the target system provides, so the generated diagrams stay usable offline and without network access.

Before building from scratch, the operator should evaluate merging that branch directly.
