# GH-1000 · Evidence-linked consolidation of Storyline, Kanban and dashboard efforts

Capture of [#1000](https://github.com/HiQS-Labs/XYZ-forge/issues/1000), which follows
[#996 checklist item 6](https://github.com/HiQS-Labs/XYZ-forge/issues/996#issuecomment-6053498474).

## Asks

1. Inventory the overlapping Storyline / knowledge-graph, Kanban / board-sync, recurring board
   upkeep, Flightdeck / release-board, Paperclip, CLIO, Whiteboard / code-intelligence and
   Sleuth / Product Compass efforts. Record a disposition for each: reuse, finish, combine, defer
   or retire.
2. Take one real failed or resumed Forge task and reconstruct its goal, attempts, current state,
   blocker, last verified outcome and safe next step from one entry point, using existing IDs.
   Add only missing references.
3. Select one primary operator interface for the first slice and make an explicit
   keep/revise/abandon call on the Paperclip visual approach.
4. Define a small implementation sequence with acceptance criteria, and link the resulting
   implementation issues from the umbrella.

## Scope limit set by the issue

Consolidation, evidence review and selection of a small end-to-end plan. No automatic migration,
deletion, deployment or merging of prototypes; no new board, knowledge graph, event bus or
task-state store; no bulk closing of older issues.
