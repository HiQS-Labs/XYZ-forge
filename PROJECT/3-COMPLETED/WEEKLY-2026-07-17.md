# Shipped to `main`: July 10-17, 2026

1. **Marathon runs are harder to derail now.** Recent harness fixes gave long-running turns more room to finish, taught the chain how to keep going when a build already produced a good artifact, and cleaned up retry/resume behavior so one stale attempt is less likely to stall the whole plan.

   The default path is less brittle here. If you are driving a real multi-lane run, the harness is now better at finishing the work it already has instead of stopping on its own bookkeeping.

2. **Vendored `.xyz` installs behave more like the real repo.** A root-semantics audit tightened how Bash and Python paths resolve the harness root, the coordination root, and the tick binary, with fresh end-to-end coverage for consumer-repo runs.

   That cuts a class of "works in the harness repo, breaks in the vendored copy" failures. Setting up or reviewing runs from another repo should take less fiddling now.

3. **Driven runs are less likely to fail on harness overhead.** One batch fixed a driver that could trip over its own lock file, added an early check for missing setup artifacts, and stopped a safe relay commit from reaching outside its allowlist.

   The practical change is fewer avoidable halts. More failures now happen for real task reasons instead of because the runner got tangled in its own scaffolding.

4. **LM Studio reached the production Aider lane.** The Aider relay shim can now use an OpenAI-compatible local endpoint without changing the default OpenRouter behavior, and the ATE fuzzing path picked up the same style of local-model support.

   If you want local model runs, the route is clearer now. If you do nothing, the existing default path stays the same.

5. **Cost feedback moved closer to the end of the run.** Driven relay sessions can now surface the `tick analyze` cost block automatically at shutdown, behind an env toggle, instead of making operators dig for it afterward.

   Reading the output takes less work. You can see what the run cost while the context is still fresh.

6. **A couple of operator shortcuts shipped too.** The new `/10days` flow can sweep recent issues into a preflighted marathon packet, and this `weekly-shipped` skill now turns a week's landings on `main` into a short recap.

   Both are small on the surface, but they reduce the clerical part of running the repo: less manual triage, less hand-written summary work.
